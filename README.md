# 📖 Overview

Currency Converter is a lightweight web application that allows users to convert currencies using live exchange rates.

The application provides an intuitive interface where users can select source and destination currencies, enter an amount, and instantly view the converted value.

# 🚀 How It Works

1. Select the source currency.
2. Select the target currency.
3. Enter the amount.
4. Click **Convert**.
5. The converted amount is displayed instantly.
